# مسافر معاك — mobile app (Flutter)

One app for passengers and drivers (Android first). Arabic, right-to-left.

## First-time setup

The repository holds the Dart code, fonts and tests. The Android project files are generated by Flutter:

```bash
cd mobile
flutter create --platforms=android --org com.musafirmaak --project-name musafir_maak .
flutter pub get
flutter analyze
flutter test
```

`flutter create .` only adds what is missing (the `android/` folder); it does not overwrite `lib/` or `pubspec.yaml`.
If it creates `test/widget_test.dart`, delete that file (it tests Flutter's sample counter app).

Then in `android/app/src/main/AndroidManifest.xml` add, above `<application>`:

```xml
<uses-permission android:name="android.permission.INTERNET"/>
```

and, for local development against `http://` (not needed with an https server), add
`android:usesCleartextTraffic="true"` to the `<application>` tag.

## Run

```bash
# backend on your machine, Android emulator:
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000/api/v1

# backend on your machine, real phone on the same Wi-Fi (start the backend with `php artisan serve --host=0.0.0.0`):
flutter run --dart-define=API_BASE_URL=http://<your-computer-ip>:8000/api/v1
```

With `OTP_EXPOSE_IN_RESPONSE=true` in the backend's `.env` (local only), the login code is filled in automatically.

## Structure

```
lib/
  main.dart, app.dart          entry point, MaterialApp (Arabic / RTL), font-scale cap
  core/
    config/env.dart            API base URL (--dart-define)
    theme/                     colours, fonts, text styles, input decoration
    strings.dart               every user-facing text (Arabic)
    api/                       ApiClient (Dio) + ApiException (Laravel error shapes)
    storage/                   TokenStore (secure storage), CacheStore (offline JSON cache)
    router/app_router.dart     routes + redirect rules (splash / login / setup / home)
    utils/                     phone normalisation, number and date formatting
    widgets/                   road sign, route marker, buttons, avatar, empty/offline states
  models/                      User, City, TravelRoute, AppConfig
  features/
    auth/                      splash, onboarding, phone + code screens, profile setup, session controller
    config/, geo/              public config and cities/routes (cached), city picker
    home/                      bottom navigation shell, home search form
    profile/                   profile tab, edit profile, photo picker, terms/privacy pages
    push/                      push interface (Firebase implementation comes with the Firebase project)
test/                          unit tests (phone, API errors, models, cache, session, routing rules)
```

State management is Riverpod; navigation is go_router. Design previews: `docs/design/`.
